# Week 0 — Scratch

This folder contains my Week 0 project for **CS50x 2026**, built using [Scratch](https://scratch.mit.edu).

## About This Project

Week 0 is all about getting comfortable with the building blocks of programming — loops, conditionals, variables, functions, events — without worrying about syntax. Scratch strips away the "typing code correctly" barrier and lets you focus purely on *logic*, which honestly made it click for me way faster than I expected.

## Why I Enjoyed This

I really enjoyed playing with Scratch. Dragging and snapping blocks together to make a sprite move, react, and respond to events made abstract programming concepts feel tangible immediately. I think this is genuinely one of the best ways to learn code basics — you get instant visual feedback, you can experiment freely without fear of "breaking" anything, and you start thinking like a programmer (breaking a big problem into small, ordered steps) before you ever have to worry about semicolons or syntax errors.

Coming from a non-coding background, this was the perfect on-ramp before moving into C in Week 1.

## What This Covers

- Sequencing, loops, and conditionals
- Events and event-driven programming
- Variables and simple state management
- Functions (custom blocks)
- Threads (multiple sprites acting independently but together)

## Tech

- **Tool:** Scratch (MIT)
- **Language:** Visual block-based programming
